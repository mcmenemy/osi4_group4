# Papers

Put paper PDFs here as `<firstauthor><year>.pdf` (lowercase, e.g. `georges2006.pdf`). The full workflow (fetching, extracting, checking, committing) and the list of papers we still want are in [`../ADDING_DATA.md`](../ADDING_DATA.md).

**PDFs are never committed.** This repo is public and many papers aren't open access, so `*.pdf` here is gitignored and left out of the Docker image. Only the extracted records in `data/records/` (values plus short evidence quotes) are committed. `NEEDS_MANUAL.txt` is regenerated by `scripts/fetch_papers.py` and is ignored too.
